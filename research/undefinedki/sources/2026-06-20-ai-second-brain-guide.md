## Core argument
Organise knowledge in portable Markdown files, use Obsidian for visible links, and Claude Code with suitable permissions to keep relevant context and links updated.

## Procedure described
1. Set up desktop Claude Code and Obsidian vault.
2. Configure Obsidian Local REST API and MCP connection; protect API key.
3. Interview owner to create initial CLAUDE.md profile.
4. Scope projects into Inputs, Process, Outputs and Feedback.
5. Work within individual project contexts, not the entire vault.
6. Codify repeatable operations as skills.
7. Add selected live connectors and schedule routine maintenance.
8. Use actual scoped permissions and read-only credentials, not prompt-based prohibitions.

## Critical assessment
- The proposed desktop/MCP flow requires a running local computer.
- Claims of fully automatic long-term accuracy need empirical testing.
- Raw material and derived knowledge should be distinguished, and references preserved.
- Explicit permissions are stronger controls than instructions alone.

## Relevance to existing GitHub AI-OS
Trial separate wiki ownership, project-level context, scoped connectors and an ingestion/retrieval evaluation. Do not duplicate Nate routing or overwrite Test-environment.
